## YukiTexture
Provide resource pack to player easily

## 設定について

### mergeTargetsの説明
ここでは、マージする対象を指定することができます。
対象を追加するために以下の記法が使用可能です。

| タイプ  | 構文                             | 記述例                                                   |
|------|--------------------------------|-------------------------------------------------------|
| フォルダ | (pluginsフォルダを起点にしたフォルダパス)      | `ModelEngine/resource pack.zip`                       |
| git  | (???.git):~/(git内での相対的なフォルダパス) | `https://github.com/azisaba/resourcepacks.git:~/life` |
